## Deliverables & Boundaries

**Zero DB / sync changes.** Do not modify `crates/quill-core/migrations/` or `crates/quill-core/src/sync/`. Built-in `dict.db` is a separate read-only SQLite resource; imported dictionaries stay local under `<app_data_dir>/dictionaries/<id>/` and never sync; multi-encounter Vocab reuses `vocab_words` with `word = canonical_lemma`; preferences store in `settings` (`dictionaries_config`, `dictionary_lemmatize`, `dictionary_show_all_matches`).

Implement all 5 phases defined in the spec:

1. **Offline dictionary pipeline, Rust engine, lemmatizer & importers (Phase 1):** Reproducible `scripts/build-dict.*` building read-only `dict.db` (≤ 20 MB, gitignored, EN Wiktionary/Kaikki + ECDICT + ZH Wiktionary/Kaikki + CC-CEDICT, CC-BY-SA 4.0 / MIT) plus a checked-in deterministic `crates/quill-core/resources/dict-test.db` fixture for Rust tests and PR CI. Implement `crates/quill-core/src/dictionary/` (built-in reader, English lemmatizer + suffix fallback + homograph `alternate_lemmas`, StarDict `.ifo`/`.idx`/`.dict[.dz]`/`.syn` from `.zip`/folder/`.ifo`, unencrypted MDict `.mdx` v1.2/v2.0 with clean v3.0 DRM rejection, per-dict local SQLite index, priority query, HTML sanitizer/theme normalizer) and dispatch commands (`lookup_dictionary`, `list_dictionaries`, `import_dictionary`, `update_dictionaries_config`, `remove_dictionary`). Resolve `dict.db` in `electron/main/paths.ts`, `core.ts`, and `host.rs` (graceful when absent), stage it in `artifacts.ts` and validate in `validate-pack.mjs` (staging `dict.db` when present, allowing `dict-test.db` fallback only under `QUILL_PACK_ALLOW_DEBUG=1` so PR CI passes on macOS and Windows). Generate the real `crates/quill-core/resources/dict.db` locally before live QA.
2. **Backend Vocab dedup & bilingual fallback prompt (Phase 2):** Dedupe `add_vocab_word` by `(book_id, word, cfi)` (or `context_sentence` when `cfi` is `None`), add `check_vocab_lemma` and `remove_vocab_lemma`, update `lookup_system_prompt` for Chinese `/pīnyīn/ 词性.`, and add Rust unit tests.
3. **Selection routing, pinyin & vocab-parse utils (Phase 3):** Add `pinyin-pro`, `src/utils/selectionRouting.ts`, `src/utils/pinyin.ts`, extend `src/utils/vocabParse.ts`, and unit-test EN + CJK cases.
4. **Adaptive selection menu & unified popover (Phase 4):** Add `src/components/ui/SmartLensIcon.tsx` (`C1-B` SVG geometry), collapse Look Up / Explain into one adaptive top row in `ReaderContextMenu.tsx`, implement `ExplainSelectionPopover` in `Reader.tsx` (dictionary + lemma + `from "…"` + alternate link + source tabs + single `ai_lookup(context)` stream + offline/no-AI fallback + AI fallback on miss + `✓ In Vocab · N` + `Save to Vocab`/`Add passage to Vocab`/`Saved` + Word-footer `Quote`/`Copy` + ephemeral passage `Explain` + gray-zone switch cancelling streams), and update reader AI tests.
5. **Vocab view, Vocab in Book, Command Search, Settings IA & `Words → Vocab` i18n (Phase 5):** Lemma-grouped `WordsView.tsx` (`DICTIONARY` + `IN YOUR READING · N`, inflected-form highlighting, per-encounter delete, Pinyin A–Z grouping/sorting, substring/pinyin/initials search), `DictionaryPanel.tsx`, `CommandSearchModal.tsx`, `TopBar.tsx`, `Home.tsx`, 4-group Settings IA (`APP`, `TOOLS`: `Dictionary` + `Look Up & Translate`, `INTEGRATIONS`: `AI Assistant` + `iCloud Sync` + `MCP`, `SYSTEM`), `DictionarySettings.tsx`, simplified `ToolsSettings.tsx`, clarified Codex copy in `AiSettings.tsx`/`codexFeatures.ts`, synced `en.json`/`zh.json` (with CC-BY-SA 4.0 / MIT attribution in Dictionary footer and About), and updated tests.

Non-goals: `quill.db` migrations, sync changes, iCloud syncing of imported dicts, `.mdd` media assets, encrypted MDict v3.0 DRM, #348 AI setup redesign, #257 persisted passage explanations, spaced-repetition UI.
